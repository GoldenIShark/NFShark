KEBIJAKAN PUBLIKASI PORTOFOLIO NFSHARK

1. Persetujuan publikasi

Publikasi website pelanggan sebagai portofolio NFShark memerlukan persetujuan pelanggan.

Persetujuan diberikan dalam dua tahap:

- Saat pelanggan mengisi formulir brief.
- Setelah website selesai, NFShark memberikan pengingat agar pelanggan memeriksa kembali pilihannya.

2. Komponen publikasi

Pelanggan dapat memberikan izin secara terpisah untuk tiga komponen berikut:

A. Tampilan website

- Website pelanggan ditampilkan melalui iframe pada halaman portofolio NFShark.
- Tampilan hanya dipublikasikan jika pelanggan memberikan izin.
- Jika website tidak mendukung iframe karena pengaturan keamanan, NFShark perlu meminta persetujuan untuk menggunakan alternatif pratinjau.

B. Nama proyek atau bisnis

- Nama proyek atau bisnis dapat ditampilkan jika pelanggan mengizinkan.
- Jika tidak diizinkan, nama tersebut tidak dipublikasikan.

C. Tautan website publik

- Tautan website pelanggan dapat dicantumkan jika pelanggan mengizinkan.
- Jika tidak diizinkan, tautan tidak ditampilkan.

3. Mekanisme persetujuan

- Setiap komponen memiliki pilihan izin tersendiri.
- Pelanggan dapat mengizinkan atau menolak setiap komponen secara terpisah.
- Jika pelanggan belum memberikan persetujuan, komponen tersebut tidak boleh dipublikasikan.
- Setelah website selesai, pelanggan diberi kesempatan untuk mengubah pilihan awalnya.
- Pelanggan dapat meminta perubahan izin atau penghapusan portofolio yang telah dipublikasikan.

4. Perlindungan informasi

Informasi pribadi dan informasi rahasia pelanggan tidak boleh ditampilkan sebagai bagian dari portofolio tanpa persetujuan yang sesuai.

Dokumen ini merupakan rancangan keputusan kebijakan publikasi portofolio NFShark.
